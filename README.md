# 🏦 Bank Loan Analysis Dashboard | Power BI

## 📌 Project Overview

The Bank Loan Analysis Dashboard is an interactive data visualization project developed using Microsoft Power BI to analyze banking loan operations, customer information, loan sanctions, disbursements, and recovery performance.

The dashboard provides insights into loan distribution, customer demographics, recovery trends, and branch-level performance. It helps transform raw banking data into meaningful business insights to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall banking loan performance.
- Track total customers and loan applications.
- Monitor loan sanction and disbursement amounts.
- Evaluate loan recovery performance.
- Analyze recovery trends over time.
- Identify product-wise and channel-wise recovery patterns.
- Understand customer characteristics influencing loan recovery.
- Explore geographical distribution of bank branches.

## 📊 Dashboard Highlights

### 1. Key Performance Indicators (KPIs)

The dashboard provides an overview of important banking metrics:

- Total Customers
- Total Loan Applied
- Total Sanction Amount
- Total Disbursed Amount
- Total Recovery Amount

These KPIs provide a quick overview of the bank's lending and recovery activities.

### 2. Loan Sanction, Disbursement & Recovery Analysis

Used a funnel visualization to compare:
- Total Sanction Amount
- Total Disbursed Amount
- Total Recovery Amount

This helps understand the movement of loan amounts across different stages of the lending process.

### 3. Loan Recovery Trend Analysis

Developed a time-based line chart to analyze recovery amounts across different dates and periods.

This helps identify recovery patterns and changes in collection performance over time.

### 4. Product-wise Recovery Analysis

Analyzed recovery amounts across different loan products using a bar chart to understand product-level recovery performance.

### 5. Channel-wise Recovery Analysis

Used a pie chart to visualize loan recovery distribution across different banking channels.

### 6. Geographical Branch Analysis

Integrated an ArcGIS map visualization to display bank branch locations using geographical coordinates (latitude and longitude).

This provides a geographical perspective of the bank's branch network.

### 7. Key Influencers Analysis

Used Power BI's Key Influencers visual to explore how customer attributes relate to recovery performance.

Analyzed factors including:
- Customer Age
- Gender
- Occupation
- Salary
- Applied Loan Amount

### 8. Decomposition Tree Analysis

Implemented a Decomposition Tree to break down recovery amounts across different customer attributes, including age, gender, occupation, and salary.

This enables deeper exploration of factors associated with loan recovery.

### 9. Q&A Visualization

Integrated Power BI's Q&A visual to support natural-language exploration of the underlying banking data.

## 🗂️ Data Model

The Power BI data model contains the following tables:

- Customer
- Branch
- Channel
- Product
- Sanction Data
- Recovery Data
- Dates

These tables support customer-level, product-level, branch-level, and time-based analysis.
